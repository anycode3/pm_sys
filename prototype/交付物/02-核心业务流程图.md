## 1. AOA 协作流程(替代传统审批)

```mermaid
flowchart TD
    A[发起人填写:类型/标的/金额/附件] --> B{系统按规则自动拉通节点}
    B -->|金额>100万| C[财务确认必选]
    B -->|金额>500万| D[法务确认自动勾选]
    B --> E[业务确认:板块负责人]
    B --> F[执行层会签:主管+专员]
    B --> G[终审:核心决策人]
    E --> H{逐节点确认}
    C --> H
    D --> H
    F --> H
    H -->|意见<20字| I[禁止提交]
    H -->|同意,意见>=20字| J[下一节点]
    H -->|提出异议+理由| K[退回发起人]
    K -->|发起人回应修改| A
    K -->|无法达成一致| L[升级至决策层裁决]
    J --> M{全部节点完成?}
    M -->|否| N{节点超时?}
    N -->|是| O[自动升级提醒->上浮驾驶舱]
    O --> H
    N -->|否| H
    M -->|是| P[终审通过]
    P --> Q[自动归档:项目档案+知识库]
```

## 2. 共识拆解流程(纪要 -> 任务)

```mermaid
flowchart TD
    A[板块负责人录入共识<br/>粘贴纪要/录音/文件] --> B[AI 按四级结构生成拆解草案<br/>L2板块目标->L3项目->L4任务]
    B --> C[人工确认:责任人/期限/优先级]
    C --> D[任务下发<br/>自动标注来源共识]
    D --> E[执行层处理任务]
    E --> F[填报进度+现场图]
    F --> G[系统自动聚合进周期汇报]
    G --> H[逐层向上:L4任务->L3周报->L2月报->L1摘要]
    E -->|卡点| I[超阈值自动升级]
    I --> J[板块负责人]
    J -->|无法解决| K[决策层风险预警]
```

## 4. 基层服务工单流转(天府绿道场景)

```mermaid
flowchart TD
    A[用户提交:Web/移动/现场扫码<br/>选类型->拍照->一句话描述] --> B{系统按类型+位置<br/>自动匹配责任主体}
    B --> C[值班岗接单]
    C --> D{按 SLA 处理}
    D -->|紧急,30分钟| E[处理中]
    D -->|常规,4-24小时| E
    D -->|超时| F[自动升级至板块负责人]
    F --> E
    E --> G[完成归档]
    G --> H[数据进入该主体运营报表<br/>跨主体共享]
```
