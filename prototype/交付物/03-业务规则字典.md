# 03 · 业务规则字典

> 开发写逻辑直接照抄本文。规则变更须同步更新本文件并记入 07-变更记录。

---

## 1. 组织与层级

| 规则 | 值 |
|------|-----|
| 层级深度 | 最多 4 级:L1 决策层 / L2 板块层 / L3 项目层 / L4 执行层 |
| 法人制 | 每个业务板块对应一个独立法人主体 |
| 板块划分(示例数据) | 种植与基地 / 生产加工 / 渠道与销售 / 投融资 / 职能支撑 |
| 跨主体数据 | 只读默认共享,写入仅限本主体 |

## 2. 目标树

| 规则 | 值 |
|------|-----|
| 节点类型 | L1 总目标(唯一)/ L2 板块目标 / L3 项目 / L4 任务 |
| 节点进度 | 下级加权汇总(默认算术平均,卡点节点可单独声明权重) |
| 溯源 | 每个节点必填「来源共识」= 会议日期 + 议题号,可跳转原文 |
| 卡点阈值 | 任务停留 >14 天自动标黄,>21 天自动升级板块负责人并上浮 L1 驾驶舱 |

## 3. AOA 协作

| 规则 | 值 |
|------|-----|
| 类型 | 项目立项 / 大额采购 / 合同签订 / 人事任免 / 自定义 |
| 节点构成 | 业务确认 + 财务确认 + 法务确认 + 执行层会签 + 终审 + 知会(只读) |
| 财务确认 | 金额 > 100 万自动必选 |
| 法务确认 | 金额 > 500 万自动勾选 |
| 执行层会签 | 项目主管 + 全部相关执行专员,不可删减 |
| 终审 | 核心决策人,进入其驾驶舱「待我决策」 |
| 强制思考 | 每节点意见 ≥ 20 字,仅点"同意"无法提交 |
| 异议 | 须写明理由,退回发起人;发起人必须回应后才能继续流转 |
| 超时升级 | 节点停留 >8 小时自动提醒;>24 小时上浮驾驶舱 |
| 归档 | 全部通过后自动写入项目档案 + 知识库 |

## 4. 任务与汇报

| 规则 | 值 |
|------|-----|
| 任务字段 | 标题 / 所属项目 / 责任人 / 优先级(高中低)/ 截止日 / 进度 / 来源共识 |
| 个人填报 | 仅「填报进度 + 上传现场图」,不写周报 |
| 汇报生成 | 项目周报每周一 09:00 自动生成;板块月报每月 1 日;决策层摘要与周报同步 |
| 数据下钻 | 汇报中任何数字可追溯至源任务 |
| 求援机制 | 「需支援」触发 AI 推荐画像匹配的支援人,并通知其主管 |

## 5. 人才画像与考核

| 规则 | 值 |
|------|-----|
| 画像构成 | 人填部分(简历/擅长)+ 系统采集部分(AOA 意见、准时率、知识贡献、带教) |
| 画像完整度 | <60% 向本人和 HR 推送补全任务,补全得虚拟币 |
| AI 匹配 | 输入业务需求 -> 推荐人选+匹配度;当前负荷 >85% 自动降权 |
| 参与度 | AOA 参与次数、意见字数、任务完成量的加权(权重待定,见遗留问题) |
| 思考投入度 | AOA 意见字数/质量 + 异议提出与被采纳次数 + 知识贡献度 |
| 分层 | 核心 / 适配 / 观察 / 待改进(比例是否强制分布待定) |
| 兜底 | 系统只给建议,去留调岗由人决定;每个分数可下钻原始记录 |

## 6. 知识库与 AI

| 规则 | 值 |
|------|-----|
| 知识域 | 投融建管退 / 产业链规则 / 产业融合 / 机构生态 / 板块经验 / 绿道运营 |
| AI 回答 | 必须标注来源文档 + 上传人 + 置信度(高/中/低) |
| 无法回答 | 自动转给领域骨干(答谢得币),答案沉淀回知识库 |
| 共享标记 | 来自其他法人主体的内容带「共享」标签,全员可见 |

## 7. 虚拟激励

| 规则 | 值 |
|------|-----|
| 币种 | 熊猫币(知识类)/ 产业币(协作类)/ 软件币(内测中) |
| 获取示例 | 上传知识 +8 / 被引用 +2 / AOA 高质量意见 +5 / 带新人 +10 / 补全画像 +5 |
| 消耗与兑换 | 未定(遗留问题) |

## 8. 培训考试

| 规则 | 值 |
|------|-----|
| 内部上岗考 | 新人必考(产业链规则+板块知识),未通过不能进入 AOA 链路 |
| 外部前置考 | 外网注册 -> 考试,≥80 分才对接职业经理人;未达标推送资料,30 天后重考 |
| 题库 | 知识库文档 AI 出题 + 人工审校 |

## 9. 基层服务工单

| 规则 | 值 |
|------|-----|
| 类型 | 报修 / 集采 / 销售 / 物业 / 其他 |
| 提交 | 选类型 -> 拍照(必填)-> 一句话描述 -> 提交;扫码可免登录 |
| 流转 | 按类型+位置自动匹配责任主体与值班人,无人工派单 |
| SLA | 紧急 30 分钟响应 / 常规 4-24 小时;超时自动升级板块负责人 |

## 10. 全局交互规则

1. AI 助手悬浮入口在所有页面可用,可感知当前页面上下文。
2. 红黄绿健康度全系统统一:🟢 正常 / 🟡 关注 / 🟥 风险。
3. 所有任务、汇报、AOA 显示「来源共识」并可跳转原文。
4. 管理操作(拆解/考核/人才池)不进移动端;移动端定位:任务、会签、看汇报、AI 问答、提单。
