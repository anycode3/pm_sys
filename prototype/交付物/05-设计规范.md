# 05 · 设计规范

> 对应高保真原型 styles.css,开发按此实现组件化。

---

## 1. 色板

|------|------|
| 主色 primary | `#0E8A6D` |
| 主色深 primary-dark | `#0C6B52` |
| 主色亮 primary-light | `#12B886` |
| 侧边栏背景(渐变) | `#0E2B21 -> #0A231B` |
| 页面背景 | `#F3F6F4` |
| 卡片背景 | `#FFFFFF` |

### 语义色(全局统一)
| 状态 | 色值 | 用途 |
|------|------|------|
| 成功/正常 🟢 | `#16A34A` | 健康、完成、进度条 |

### 中性色
| 用途 | 色值 |
|------|------|

| 次文字 | `#6B7280` |

## 2. 字体与字号

- 字族:`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- **基础字号 15px**(全年龄段适配刻意放大,不用 12/13px 做正文)
- 层级:页面大标题 20px 粗 / 卡片标题 15px 粗 / 正文 14-15px / 辅助说明 12.5-13px / 指标数字 26-30px 特粗
- 行高:正文 1.6-1.7

## 3. 布局

| 项 | 值 |
|----|-----|
| 左侧导航 | 固定 224px,深色,分组标签 11px |
| 顶部工具栏 | 高 62px,白色,含搜索/通知/用户 |
| 内容区 | 最大宽 1400px,内边距 24×28 |
| 栅格 | 12 列;常用 4 卡/2+1(2fr+1fr)/三栏 |
| 间距基数 | 4/8/12/16/24 |
| AI 助手 | 右下角悬浮 56px 圆钮,所有页面固定 |

## 4. 组件规范

| 组件 | 规范 |
|------|------|
| 卡片 | 圆角 14px,边框 1px #E4EAE7,内边距 18×20,轻投影 |
| 按钮 | 圆角 9px;主(绿底白字)/次(白底绿边)/中性(灰底)/危险(白底红边);高度 38px,小号 28px |
| 徽章 badge | 圆角 20px,12px 字,语义色 10% 透明底+同色系深字 |
| 进度条 | 高 10px,圆角 6px,绿渐变;警告琥珀渐变;风险红渐变 |
| 时间线 | 左侧 2px 轴线;完成=实心绿点,当前=绿边白心+光圈,未到=灰边 |
| 树节点 | 四级标签色:L1 深绿底白字 / L2 绿底白字 / L3 浅绿底深字 / L4 灰底 |
| 表格 | 表头灰底 12.5px,行 hover 浅绿背景,斑马纹可选 |
| 头像 | 圆形 42px,首字白字,6 色轮换 |
| 消息通知条 | 圆角 12px,语义色浅底+同色边框,左侧图标 |
| 输入框 | 圆角 9px,聚焦绿边+12% 绿光晕 |

## 5. 图表风格(轻量原则)

只用四类:横向进度条、迷你趋势折线(SVG)、甘特条、雷达图。**不做** 3D、不做复杂大屏特效。数字一律加大加粗,辅助信息小字灰。

## 6. 图标与表达

- 导航/类型用 emoji 级图标+文字双通道(适配 60 后用户,不允许纯图标按钮)
- 状态一律"颜色+形状+文字"三重编码(色盲友好)

## 7. 移动端规范

- 底部五 Tab(任务/AOA/汇报/AI/我的),当前项绿色加粗
- 卡片圆角 12px,触摸目标 ≥44px
- 表单提交按钮全宽,危险操作与主操作并排但视觉区分
- 免登录页面隐藏所有框架导航,仅保留流程

## 8. 文案语气

- 界面用正式职称,禁止网络用语(不出现"牛马"等)
- 空状态给行动指引而非冷冰冰的"暂无数据"(如"暂无现场影像,催执行层上传")
- 规则类提示说明"为什么"(如"≥20 字必填:防止无脑同意")
