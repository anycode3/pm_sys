# 产业协同平台 · 原型说明书(先读这个)

> 版本:v0.2 · 2026-08-30 · 原型设计阶段交付

---

## 1. 产品定位(一句话)

生态型全产业运营企业的**内部协作作战系统**:把核心管理者的会议共识逐层碎片化拆解到岗、跨法人主体共享信息、按画像调度人力、自动生成汇报,替代传统 OA 的权力导向审批。

**不是什么**:不是 OA 审批工具、不是普通项目管理软件、不是 IM。

## 2. 目标用户与层级(四级 · 法人制)

| 层级 | 职称 | 职责 | 主用页面 |
|------|------|------|----------|
| L1 决策层 | 核心决策人 | 定总目标、终审 AOA、看盘 | 驾驶舱、项目详情 |
| L2 板块层 | 板块负责人(五大法人主体) | 共识拆解、分派任务、发起 AOA | 板块工作台 |
| L3 项目层 | 项目主管 | 项目推进、汇报汇聚 | 项目详情、目标树 |
| L4 执行层 | 执行专员 | 执行任务、会签 AOA、共建知识库 | 我的任务、移动端 |

组织规模:当前数十人,架构需平滑支撑数万人。

## 3. 三大核心场景

1. **共识落地**:板块负责人粘贴会议纪要 -> AI 按四级结构拆解任务 -> 人工确认责任人 -> 下发,任务全程可溯源到会议原文
2. **AOA 协作决策**:发起事项自动拉通全链路节点(业务/财务/法务/执行层会签/终审),每节点强制 ≥20 字意见,超时自动升级
3. **零填报汇报**:任务数据自动聚合为项目周报 -> 板块月报 -> 决策层摘要,每个数字可下钻到源任务

## 4. 本期范围边界

**已定(本期原型覆盖)**:九大模块全部 16 个 Web 页面 + 移动端 5 屏。
**未定(原型中为占位,开发前需拍板)**:
- 虚拟币(熊猫币/产业币/软件币)的兑换与消耗规则
- AI Agent 的具体模型与知识库检索方案(原型仅表达交互形态)
- 外部前置考试的题库来源与收费策略
- 虚拟币与 KPI 的挂钩比例
